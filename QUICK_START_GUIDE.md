# OperationHub - Quick Reference Guide

## 🎯 Project Overview
OperationHub is a Spring Boot application with JWT authentication, user management, and RESTful APIs.

## 📁 What are `target/` and `out/` folders?

### ❌ DO NOT COMMIT THESE FOLDERS TO GIT

**target/** - Created by Maven
- Generated by `mvn clean compile` or `mvn package`
- Contains compiled `.class` files and the `.jar` artifact
- Safe to delete - regenerated on next build
- Size: Usually 50-200 MB

**out/** - Created by IntelliJ IDEA
- Generated when running/building in IDE
- Contains compiled classes
- Safe to delete - regenerated on next build
- Size: Usually 10-50 MB

**.gitignore entry to use:**
```
target/
out/
*.class
*.jar
*.war
```

## 🛠️ Port Configuration

The application runs on port **9090** by default. If port is already in use:

### Fix 1: Kill Process Using Port 9090
```powershell
# Find process using port 9090
netstat -ano | findstr :9090

# Kill the process (replace PID with actual process ID)
taskkill /PID <PID> /F

# Example:
taskkill /PID 12345 /F
```

### Fix 2: Change Port in application.properties
Edit `src/main/resources/application.properties`:
```properties
server.port=8080  # or any available port
```

## 🔐 JWT Configuration

### Current Secret (CHANGE BEFORE PRODUCTION!)
```properties
jwt.secret=mySecretKeyForJWTTokenGenerationMustBeAtLeast256BitsLongChangeThisToSomethingSecure12345
jwt.expiration=86400000
```

### Generate a Secure Secret Key
Use this online tool or command:
```bash
# PowerShell
$bytes = New-Object byte[] 32
$rng = New-Object System.Security.Cryptography.RNGCryptoServiceProvider
$rng.GetBytes($bytes)
[Convert]::ToBase64String($bytes)
```

### Production Configuration
Set environment variables:
```powershell
$env:JWT_SECRET = "your-secure-key-here"
$env:JWT_EXPIRATION = "86400000"
```

## 🐛 Troubleshooting

### Port Already in Use
```bash
# Check what's using the port
netstat -ano | findstr :9090

# Kill the process
taskkill /PID <PID> /F
```

### Application Won't Start
1. Check if port 9090 is available
2. Verify Java is installed: `java -version`
3. Check logs for errors
4. Clean and rebuild: `.\mvnw.cmd clean compile`

### Token Validation Fails
- Ensure token has "Bearer " prefix
- Check if token is expired
- Verify jwt.secret matches

### Database Connection Error
- Ensure H2 driver is available
- Check application.properties for datasource config
- Try: `.\mvnw.cmd clean compile`
